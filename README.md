# Aurora 极光音乐 (Aurora Music)

一个功能完整的 **Windows 本地音乐播放器** 桌面应用（Electron），专注于「听得舒服、看得清楚、数据记得住」。

![icon](assets/icon-256.png)

---

## ✨ 功能总览

### 🎨 外观
- **6 套界面风格**，一键切换：
  | 风格 | 说明 |
  | --- | --- |
  | 玻璃拟态 (glass) | 毛玻璃通透质感，可配自定义背景图 |
  | 扁平化 (flat) | 干净利落的纯色块 |
  | 新拟态 (neumorph) | 柔和凸起 / 内凹阴影 |
  | 拟物化 (skeuo) | 金属拉丝、真实质感与高光 |
  | 暗夜极简 (midnight) | 深色高对比，护眼 |
  | 马卡龙 (macaron) | 明亮活泼的糖果色 |
- **自定义背景**：任意本地图片，可调 **模糊 / 变暗 / 饱和度 / 填充方式**；也可以选动态极光渐变或纯色。
- **强调色**：10 组预设主色 + 自定义次色，界面圆角、密度（紧凑/标准/宽松）均可调。
- 无边框自绘窗口、界面缩放、悬浮「音频浮动板块」。

### 🎵 曲库与格式
- 递归扫描任意文件夹，**支持 MP3 / OGG / M4A / FLAC / WAV / AAC / OPUS**（同时兼容 `.oga .m4b .mp4 .weba .webm .aiff .wma`）。
- **自动读取标签**（标题/歌手/专辑/流派/年份/音轨号）、**内嵌封面**、同目录 `cover.jpg` 兜底、比特率 / 采样率 / 声道 / 无损标识。
- 没有标签的「裸文件」会按文件名推断，约定为 **「歌名 - 歌手」**（例如 `Refrain - 阿南亮子.mp3` → 歌名 `Refrain`，歌手 `阿南亮子`）；文件名中没有 ` - ` 时整个文件名当作歌名。
- 扫描结果与元数据 **缓存**，二次扫描秒开；解析规则升级时会自动丢弃旧缓存并重建一次曲库。
- 拖拽文件或文件夹到窗口即可导入。
- **流畅拖拽排序**（FLIP 动画），自定义顺序会被记住；也可按标题/歌手/专辑/时长/我的累计听歌时长/播放次数等排序。
- 列表视图 / 网格卡片视图；搜索支持标题、歌手、专辑、格式、文件名。
- 收藏、最近播放、多个播放列表（新建 / 重命名 / 导出 JSON / 导入）。

### ▶️ 播放
- **切歌过渡效果（可切换、可调时长）**：
  - `直接切换` — 无过渡
  - `淡出淡入` — 先渐弱再渐强（带短暂间隙）
  - `交叉淡化` — 两首歌平滑重叠
  - `缓慢融合` — 长交叉淡化，适合慢歌
  - `快速闪接` — DJ 式快速压低再拉起
  - `无缝衔接` — 零间隙，适合连续专辑（会预加载下一首）
- 播放模式：**顺序播放 / 列表循环 / 单曲循环 / 随机播放**（播放栏一键循环切换）。
- **变速不变调**（0.5×–3.0×，Chromium 时间伸缩）与 **独立变调**（−12 ~ +12 半音，自研 AudioWorklet 双抽头颗粒变调器）——两者互相独立，也可以关闭「变速不变调」得到磁带式变速变调效果。
- **10 段参数均衡器**（31Hz–16kHz，±12dB）+ 前置放大，15 组内置预设（流行/摇滚/古典/爵士/人声/低音增强/重低音/高音增强/电子/民谣/夜晚/电影/V型/播客/默认）与自定义预设保存。
- **音效插件系统**（详见下文），可叠加串联。
- 音量 / 静音 / 记忆播放位置 / 自动播放下一首 / 系统媒体键（Windows SMTC，音量弹窗显示曲目并可控制）。
- **记住上次播放**：重启后自动把上次在听的那首歌装回播放器、并停在退出时的位置，点一下播放就接着听（不需要额外设置）。
- **手动设置封面**：曲库工具栏「🖼 添加歌曲封面」可给选中的歌（或正在播放的那首）换封面；图片按最长边 560px 等比缩放后存入封面缓存，显示时按容器居中裁剪，不改动音乐文件本身。

### 🎤 歌词（中文 + 英文 + 日语）
- 支持 **LRC** 格式，自动识别 **UTF-8 / UTF-16 / GBK / GB18030 / Big5** 编码（中文歌词不会乱码）。
- 查找顺序：同名 `.lrc` → 同目录 `歌词/ lyrics/ lrc/` 子目录 → 父目录 → 曲库根目录歌词夹 → 应用歌词缓存目录 → **音频内嵌歌词**（ID3 USLT / Vorbis LYRICS）→ **在线歌词**（见下）；还会按「歌名 / 歌手+歌名」模糊匹配。
- **在线歌词**：在线音乐点开后自动去对应平台取词 —— **QQ音乐 / 酷狗音乐 / 网易云音乐** 各走自己的官方歌词接口，拿不到就退到「酷狗按 `歌手 - 歌名` + 真实时长」再搜一次，再不行去网易云按歌名搜同名歌。带真实时长很关键，否则搜到的多半是 30 秒铃声片段。各平台开头的「词：/曲：/制作人：」等制作名单会自动剔除；歌词只在内存缓存，不写进你的歌词文件夹。
- **哔哩哔哩也有歌词**：B 站的 CC 字幕接口对匿名客户端返回空数组（实测多个中字 / 双语视频均为 0 条），所以走「清洗投稿标题 → 跨源匹配」——从标题里剥掉 `【】`、`MV / 4K / 动态鼓谱 / 完整版 / 翻唱` 之类的噪声，猜出歌名与歌手，再去网易云 / 酷狗找同一首歌。B 站的「歌手」字段其实是 UP 主，所以匹配只认**标题 + 时长邻近**（容差放宽到 8 / 15 / 30 秒）。实测「甩葱歌原版」「Lemon【米津玄師】动态鼓谱」都能命中。
- **中日 / 中英互译**：同一时间戳的中外两行会自动合并为「主行 + 翻译行」；QQ / 酷狗的日语歌常常只有原文，这时会自动去网易云找同一首歌的 `tlyric`，按时间戳（±0.6 秒）贴回原文行形成双语。可在「设置 → 播放与过渡 → 日语字幕自动翻译」关闭。
- **日语字体**：中文 / 西文 / 日文 **三套字体分别设置**，按行内容自动切换（日语行含假名即判定为日语）。字幕放映与桌面歌词浮层同步生效。
- 卡拉OK 染色、滚动居中、点击歌词行跳转播放位置。
- 可 **导入 .lrc 文件**、**内置编辑器** 编辑歌词并保存到歌词库。
- 在「正在播放」页点 **🔍 查找歌词 / 🔄 重新载入歌词** 可强制重新获取（缓存会被绕过）。

### 🎬 字幕放映（整页沉浸视图）
- 一键进入「字幕放映」：**模糊封面马赛克打底 + 极光光晕 + 居中大字歌词**，唱到的部分高亮、唱过的淡出，上下行由遮罩渐隐。
- **中日英混排**：每一行按内容自动选字体（日语行用日文字体，中文行用中文字体，西文行用西文字体），日语原文 + 中文译文显示成「原文 + 翻译」两行。
- 逐字推进按播放进度平滑推进（本地插值，视觉 60fps）。
- 顶栏曲名/歌手/时钟与播放控制，底栏进度条；配合 **F11 全屏** 即可当放映模式。
- 进入方式：侧栏「🎬 字幕放映」、标题栏 🎬 按钮，或快捷键；`Esc` 退出。

### 🖥️ 桌面歌词浮层（独立透明窗口）
- 无边框、透明、始终置顶、可拖动；**圆形封面**在左，逐字歌词在右。
- **逐字染色**：唱到的字变主题色，未唱部分保持淡色；长句按进度分段推进。支持 **整句高亮 / 逐字 / 极简** 三种风格。
- **字号固定**：正在唱 / 翻译 / 下一句三行**用同一个字号**（默认 26px），大小不随句子长短、也不随行角色变化；主次只靠颜色与透明度区分，所以句子换行时不会看到字忽大忽小。
- **调色板 / 外观**：3 套配色预设 + 自定义「已唱色 / 未唱色」取色器；字号、行间距、不透明度、封面开关与大小、翻译、下一句、半透明底板与底板透明度。
- **节奏可视化**：封面随低频**脉动**，可选叠加歌词下方的**横向频谱**；灵敏度 0.4×～2.5×，可整体关闭。
- **窗口尺寸固定**：宽高只由设置决定（字号 / 封面大小与开关 / 行距 / 翻译 / 下一句 / 频谱），**与歌词内容无关** —— 换句、换歌都不会忽大忽小（以前按当前句的实际宽度「贴紧内容」，长句撑开、短句缩回，看着就是字幕框一直在变）；超宽的句子在框内自动折行。
- 不可手动拉伸；位置会被记住，可一键**重置位置**（只把窗口移回屏幕中间，不改尺寸）。
- **操作**：拖动窗口任意空白处或封面即可移动；在浮层上 **右键** 打开外观面板（面板内含「重置位置 / 主窗口 / 关闭歌词」）。
- 主界面「设置 → 播放与过渡 → 桌面歌词」可开关、选风格、调字号；同处还有 **日文字体** 与 **日语字幕自动翻译**。
- 日语歌词在浮层里同样会切到日文字体，日语原文 + 中文译文显示成两行。
- 快捷键：`Ctrl+L` 开关浮层，全局 `Ctrl+Alt+L`（窗口不在前台也生效）。

### ⌨️ 快捷键
- **全局快捷键**（窗口不在前台也生效）+ **媒体键**（播放/暂停、上一首、下一首），全部可自己按键录制，可单独开关，并提供「占用检查」。
- 保留一组 **固定的应用内键盘操作**（不可配置）：`空格` 播放/暂停、`← →` 快进/后退 5 秒、`↑ ↓` 音量、`Esc` 关闭弹层、`/` 聚焦搜索框。
- 点右上角 **✕ 会隐藏到托盘并继续播放**，不会中断音乐；要退出请用托盘菜单的「退出」。

### 📊 听歌时长统计（核心需求）
- **每日 / 每月 / 每年累计听歌时长**，以及 **日均、有效听歌天数、自然日均**。
- **图表支持「天 / 周 / 月 / 年」四档切换**：右上角四个字任选一档，同一张图就地换数据（最近 30 天每日 / 最近 12 周每周 / 最近 12 个月每月 / 按年），标题里带该档合计与有效记录数；窗口缩放与进出全屏会自动重画，不会拉伸变形。你选的那一档会记住。
- **每天听过的每一首歌都会单独记录时长**（`stats.json` 的 `days[日期].tracks[曲目]`），所以在天 / 周 / 月 / 年任意粒度下都能回溯到是哪些歌撑起来的。
- **每首歌的累计听歌时长**：曲库列表直接有一列「累计听歌」，可排序；「正在播放」页也显示当前歌曲累计；统计页有完整的 **每首歌时长排行榜**（含来源、播放次数、上次播放时间）。
- **在线音乐（含「我的收藏」里的在线歌）同样计入统计**：在线曲目不在本地曲库里，所以统计时会把它和歌名 / 歌手 / 音源一起落盘，排行榜里会用「🌐 音源名」标出来，和本地曲目的「💾 本地」区分；收藏过的在线歌还能直接从排行榜点回去播放。
- 今日目标进度条；单曲最短计入时长可调（默认 5 秒，避免快速切歌刷数据）；可 **导出 JSON / CSV** 与一键重置。

### 🔌 音效插件（类似 QQ 音乐的音效）
内置 **16 个音效插件**：3D 环绕声、大厅混响、房间混响、超重低音、清澈人声、人声消除（卡拉OK）、8D 环绕、夜晚柔和、温暖胆机、摇滚现场、车载音响、录音棚监听、Lo-Fi 磁带、电子舞曲、合唱空间、电话音效、梦幻空间。

- 每个插件有 **可调参数滑块**，可任意组合叠加，实时生效。
- **可导入自定义插件**：
  - `.auroraplugin` / `.json` 描述文件（声明式效果图 + 参数面板，见下文格式）；
  - 直接导入 `wav/ogg/mp3/flac/m4a` **脉冲响应文件**，自动生成卷积混响插件。
- 支持的效果节点：`gain` `biquad`(均衡/滤波) `convolver`(卷积混响) `delay` `chorus` `autoPan` `compressor` `waveshaper`(胆味失真) `vocalsRemover`(声道相减消人声) `stereo`。

### 🔊 音频浮动板块
- 可拖动、可缩放的悬浮面板，实时频谱：**频谱柱 / 镜像柱 / 波形 / 环形 / 粒子** 五种可视化。
- 迷你播放器窗口（独立置顶浮窗）：封面、标题、进度、播放控制、模式、桌面歌词开关、迷你频谱与当前歌词行。

### 🌐 在线音乐（双音源分栏：哔哩哔哩 / 所有音乐）
- 侧栏「**🌐 在线音乐**」，页面顶部有两个分栏：
  - **📺 哔哩哔哩音源** —— 只搜哔哩哔哩（`electron/online.js`）。
  - **🌐 所有音乐** —— 聚合音源，**不含哔哩哔哩**，同时查 **QQ音乐 + 酷狗音乐 + 网易云音乐**（`electron/aggregator.js`）。
  - 两个分栏各自记住自己的关键词和搜索结果，来回切换不会互相清空。
- 「所有音乐」里的同一首歌**只显示一行**：按 **QQ音乐 → 酷狗音乐 → 网易云音乐** 的优先级合并去重，优先保留 QQ 音乐的专辑 / 时长 / 封面。
- 在顶部搜索框输入关键词（例如 `周杰伦 晴天`）**按回车**即可搜索；结果展示 **歌名 / 歌手 / 专辑（哔哩哔哩分栏显示为 UP主）/ 封面 / 时长 / 来源**，点任意一首直接播放。
- **不需要 API Key、不需要任何代理、不需要自建服务器**，国内网络直连；全部逻辑跑在 Electron 主进程内，播放时按需实时解析音频直链，不落地缓存音频文件。
- 加载 / 播放 / 暂停 / 继续 / 上一首 / 下一首 / 音量 / 拖进度条 / 变速变调 / 切歌过渡全部复用现有的本地播放引擎；迷你窗、桌面歌词浮层与系统媒体控制（SMTC）同样会显示在线封面。
- 在线曲目与本地曲库**完全隔离**：不会混进「全部音乐」「最近播放」，也不写进本地曲库 `library.json`。
- 搜索结果、「正在播放」页和底部播放栏都有 **♡ 收藏** 按钮（快捷键 `Ctrl+D`）。收藏的在线歌曲会出现在侧栏「**❤️ 我的收藏**」里，单独排在本机收藏的下方一段「在线收藏」，可照常点播、上下首；侧栏收藏计数 = 本机收藏 + 在线收藏。
- 在线收藏存放在 `userData/online-favorites.json`，与本地曲库 `library.json` 分开，删掉它只会清空在线收藏。
- **在线歌词**：播放任意在线音源（QQ音乐 / 酷狗音乐 / 网易云音乐 / **哔哩哔哩**）的曲目时都会自动取歌词，日语 / 外语歌还会自动补中文翻译（中日 / 中英双语）；详见上面的「🎤 歌词」章节。
- 音源降级是**互相独立**的：「所有音乐」分栏里三个 provider 并发查询，其中一个挂了另外两个照常出结果，页面上会显示「QQ音乐 30 首 · 酷狗音乐 32 首 · 网易云音乐 暂时不可用」。全部挂掉才报错，并在页面上给一个「重试」按钮。
- **点击任何一首都能出声**：某个平台把这首歌设成会员 / 付费（匿名客户端拿不到播放地址）时，主进程会拿「歌名 + 歌手 + 时长」依次去**酷狗音乐 → 网易云音乐 → 哔哩哔哩**找同一首歌出流（同名 + 同歌手 + 时长差 ≤3 秒才算匹配），三级都匹配不到才会明确报错，不做静默失败。所以像「周杰伦 晴天」这种 QQ 不给凭证、酷狗要会员、网易云又没有版权的歌，最后会落到 B 站上的完整版投稿来播。
- 音频流通过 `aurora://local/stream?v=<id>[&s=<音源>][&q=<提示>]` 由主进程代理并按 HTTP Range 透传，封面通过 `aurora://local/thumb?u=<url>`（直链）或 `aurora://local/thumb?s=<音源>&i=<封面id>`（需要先解析一次）代理，因此不放开 CSP、也不引入跨域问题。
- 音频直链带时效（通常几小时），过期或被下线时**自动重新解析一次**；再失败就停止并把错误显示在页面上，不做无限重试。
- ⚠️ 早先的 YouTube Music 方案（youtubei.js）需要能访问 `music.youtube.com`，在无法直连的网络下会报「在线音乐初始化失败：fetch failed」，现已改为哔哩哔哩 + 聚合音源。

## 📦 安装与运行

### 方式一：安装包（推荐）
运行 `AuroraPlayer-Setup-1.0.1.exe`，安装程序会自动创建 **桌面快捷方式** 和开始菜单项。

### 方式二：免安装绿色版
直接运行 `AuroraPlayer-Portable-1.0.1.exe`，或在应用内「设置 → 数据与关于 → 创建桌面快捷方式」生成桌面图标。

### 方式三：源码运行
```bash
npm install
npm start
```

## ✅ 自检（--smoke）

`AuroraPlayer.exe --smoke` 会启动一次完整的端到端自检，约 40 秒后写出 `smoke-report.json`，包含：

- 界面是否完成启动、各视图能否渲染
- 曲库扫描结果（数量 / 时长 / 标签 / 格式分布）
- 歌词查找与解析行数
- **实际播放验证**：播放 5 秒后检查 `currentTime` 是否推进、Web Audio 分析器是否有信号（证明解码与音频图可用）
- 6 套主题、6 种切歌过渡、4 种播放模式、均衡器、变速变调、音效插件开关
- 听歌时长统计是否写入
- 桌面歌词窗口与迷你播放器窗口能否创建与渲染

## 🧩 自定义音效插件格式

把下面的 JSON 保存为 `我的音效.auroraplugin`（或 `.json`），在「音效插件 → 导入插件」中选择即可：

```json
{
  "name": "我的低音炮",
  "author": "你的名字",
  "version": "1.0.0",
  "desc": "加强 60Hz 与 120Hz 的低频冲击",
  "category": "动态",
  "params": [
    { "key": "gain", "label": "强度", "min": 0, "max": 12, "default": 6, "unit": "dB" }
  ],
  "graph": [
    { "type": "biquad", "params": { "type": "lowshelf", "freq": 90, "gain": "{gain}", "q": 0.7 } },
    { "type": "biquad", "params": { "type": "peaking", "freq": 60, "gain": "{gain}", "q": 0.9 } },
    { "type": "compressor", "params": { "threshold": -20, "knee": 14, "ratio": 5, "attack": 0.004, "release": 0.2 } }
  ]
}
```

- `params` 里的 `key` 可以用 `"{key}"` 或 `"-{key}"` 的形式在 `graph` 中引用，界面会自动生成滑块。
- `graph` 中每个节点串联连接，`type` 支持：`gain` `biquad` `convolver` `delay` `chorus` `autoPan` `compressor` `waveshaper` `vocalsRemover` `stereo`。

## 🛠 技术要点

- **Electron** 无边框多窗口：主窗口 + 桌面歌词浮层 + 迷你播放器。
- **自定义 `aurora://` 协议** 统一同源地提供页面与本地音频（支持 HTTP Range 分段流式读取，保证拖动进度条即时响应），并让 `<audio>` → Web Audio 的分析器不被跨域污染。
- **双解码器 (dual deck) + Web Audio 图**：
  `deckA/deckB → 输入 → 10×BiquadFilter → 前置放大 → 插件链 → 变调 Worklet → Analyser → 主音量 → 输出`
  双解码器让交叉淡化/闪接等过渡效果可以真正重叠播放。
- **自研变调 AudioWorklet**：双抽头颗粒重叠相加 + 正弦窗归一化，与变速完全解耦。
- 元数据由 `music-metadata` 解析（打包时通过 `asarUnpack` 解包为真实文件以便 ESM 动态导入）；封面用 Electron `nativeImage` 缩放后缓存为 JPEG。
- **在线音乐 · 哔哩哔哩音源**（`electron/online.js`）：由主进程直接调用哔哩哔哩的公开 web 接口 —— `x/web-interface/search/type` 搜索，`x/web-interface/view` 取 cid，`x/player/playurl`（`fnval=4048`）取 dash 音频直链，全部为匿名访客访问，无需登录也无需 API Key。B 站有风控，请求需补齐 `Accept` / `Origin` / `Referer` 与 `buvid3` cookie（首次使用时自动从首页取，取不到则本地生成一个），否则会返回 `412` 或 `-412`。
- **在线音乐 · 所有音乐**（`electron/aggregator.js`）：聚合音源，三个 provider 并发查询、各自降级：
  - **跨平台兜底链**：酷狗 → 网易云 → 哔哩哔哩。华语主流歌经常是「QQ 不给凭证 + 酷狗要会员 + 网易云没有版权」三连，所以最后一站交给 B 站（复用 `electron/online.js` 那条链路）。命中 B 站时不再走聚合音源自己的直链透传，而是直接调用 B 站的 `streamResponse`（要带 `buvid3` cookie，请求头也不一样）。
  - **B 站的 dash 音频地址优先级**：接口每条音轨给一个 `baseUrl` + 若干 `backupUrl`，`baseUrl` 常常落在 P2P 节点（`*.mcdn.bilivideo.cn:8082`），这个节点在不少网络下连接会被重置（`ECONNRESET` / `fetch failed`），所以代码会优先挑非 `.mcdn.` 的普通 CDN 地址。
  - **QQ音乐** —— `u.y.qq.com/cgi-bin/musicu.fcg` 的 `music.search.SearchCgiService / DoSearchForQQMusicDesktop` 搜索（匿名访客即可，无需登录）。该接口有频率限制，连打几次会返回 `reqCode:2001`，所以请求串行排队并强制最小间隔 1.2 秒，命中限流时页面上会提示「QQ音乐暂时限制了搜索频率」；封面直接拼 `y.qq.com/music/photo_new/T002R300x300M000<albumMid>.jpg`。
  - **QQ音乐为什么只做搜索**：官方自 2023 年起不再向匿名客户端下发播放凭证（`vkey` 各接口一律返回 `purl:""`）。所以点击 QQ 的曲目时，主进程会拿「歌名 + 歌手 + 时长」去酷狗、网易云、哔哩哔哩找同一首歌出流（同名 + 同歌手 + 时长差 ≤3 秒才算匹配），匹配不到会明确提示，不做静默降级。收藏里的 QQ 歌曲在重启后依然能播：播放地址会带上 `&q=<base64url>` 的歌名/歌手/时长提示，不依赖进程内的搜索缓存。
  - **酷狗音乐** —— `songsearch.kugou.com/song_search_v2` 搜索（返回 `Privilege` / `PayType` / `FileHash` / `HQFileHash` / 时长 / 封面模板等完整元数据），`m.kugou.com/app/i/getSongInfo.php?cmd=playInfo&hash=<FileHash>` 取播放直链（免签名；失败时退回 `trackercdn.kugou.com/i/?cmd=4&key=md5(hash+"kgcloud")`），封面把接口给的 `imge.kugou.com/.../{size}/...jpg` 模板里的 `{size}` 换成 `240` 后由主进程代理；均无需 cookie、无需 key。`Privilege` / `PayType` 非 0 的是会员/付费曲目，匿名拿不到直链，此时自动换网易云出流。
  - **网易云音乐** —— 走公开聚合接口 `music-api.gdstudio.xyz/api.php`（`types=search` / `types=url` / `types=pic`），该接口偶发 503，所以带 3 次递增退避重试；封面地址带加密段、无法由 `pic_id` 推出，因此由主进程按 id 解析后再代理。
  - 搜索结果按关键词命中度排序：歌手命中权重高于标题，歌名是搜索词子串时额外加成，并给「伴奏 / 翻唱 / Live / DJ / 钢琴版」之类的水货标题扣分（用来把翻唱压到正版后面）。最后按归一化后的「标题 + 歌手」跨音源去重，同一首歌只留优先级最高的那一行。
  - 直链缓存 15 分钟并做并发去重；遇到 403/404/410 清缓存重解析一次，后缀 Range 遇 416 退回整段重发。
- **在线歌词**（`electron/lyrics-online.js`）：`lyrics:find` 先走本地/内嵌歌词，拿不到且曲目来自在线音源时再去平台取词（哔哩哔哩也取，见下）。
  - **QQ音乐** `c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg?songmid=<mid>&format=json&nobase64=1&g_tk=5381`（返回体的 `content-type` 是 `text/html`，但 body 其实是纯 JSON）。
  - **网易云音乐** `music.163.com/api/song/lyric?id=<id>&lv=1&kv=1&tv=-1`，同时取 `lrc` 与 `tlyric` 拼在一起，渲染层的双语合并会自动配对成「原文 + 翻译」。
  - **酷狗音乐** `krcs.kugou.com/search` 找候选（`accesskey` + `id`）再 `lyrics.kugou.com/download?...&fmt=lrc` 下载 base64 LRC；**必须带真实时长**（`&duration=<ms>`），否则首条候选常是 30 秒铃声片段。候选按标题/歌手/时长差打分取最优。
  - **哔哩哔哩**：B 站的 CC 字幕接口 `api.bilibili.com/x/player/v2` 对匿名客户端返回的 `data.subtitle.subtitles` 实测恒为空数组（中字 / 双语视频都一样），所以改成跨源匹配 —— `biliParts()` 从投稿标题里摘出 `【】` 内容当歌手候选、剥掉 `MV / 4K / 动态鼓谱 / 完整版 / 翻唱 / 罗马音` 之类的噪声词，再用 `matchScore()` 去网易云官方搜索（主）/ 酷狗 `krcs`（次）找同一首歌。**B 站的 `artist` 字段是 UP 主而不是歌手**，所以歌手不命中不扣分，主要靠标题（相等 +4 / 互相包含 +2）与时长邻近（容差放宽到 8 / 15 / 30 秒）判定，总分 <4 不认。
  - **中日 / 中英互译**：`attachTranslation()` —— 拿到原文后如果还没有双语（同一时间戳只有一行），且原文含假名或压根不含汉字，就去网易云按同一首歌取 `tlyric`，把译文按时间戳（±0.6 秒找最近）贴到原文行下面，时间戳相同 → 渲染层自动合并成两行。阈值更严（≥5 分），宁可没有也不贴错歌。
  - 任一平台取不到就统一退到「酷狗按 `歌手 - 歌名` + 真实时长」→「网易云按 `歌名(+歌手)` 搜同名歌」两级兜底；各平台开头塞的标题行与「词：/曲：/编曲：/制作人：」等制作名单会在**开头连续段**内剔除（只作用于在线歌词，本地 `.lrc` 解析逻辑未改动）。结果按 LRU 在内存缓存 150 条，不写磁盘。
- **歌词 / 字幕的语言与字体**：`src/js/util.js` 的 `langOf()` 把每行判成 `jp`（含假名）/ `zh`（含汉字）/ `en`，`parseLrc()` 把结果写进 `line.lang`；主界面歌词、字幕放映、桌面歌词浮层三处共用这个标记，分别套 `--ly-cn` / `--ly-en` / `--ly-jp` 三套字体（由「设置 → 播放与过渡 → 日文字体」写入，默认 `Meiryo / 游ゴシック` 栈）。译文行固定用中文字体，避免日文原文 + 中文译文时译文也被日文字形带走。
- 渲染层零框架、纯原生 JS/CSS，启动快、体积小。
