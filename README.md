# Aurora 极光音乐 (Aurora Music)

一个功能完整的 **Windows 本地音乐播放器** 桌面应用（Electron），专注于「听得舒服、看得清楚、数据记得住」。

![icon](assets/icon-256.png)

---

## ✨ 功能总览

### 🎨 外观
- **6 套界面风格**，一键切换：
  | 风格 | 说明 |
  | --- | --- |
  | 玻璃拟态 (glass) | 毛玻璃通透质感，可配自定义背景图 |
  | 扁平化 (flat) | 干净利落的纯色块 |
  | 新拟态 (neumorph) | 柔和凸起 / 内凹阴影 |
  | 拟物化 (skeuo) | 金属拉丝、真实质感与高光 |
  | 暗夜极简 (midnight) | 深色高对比，护眼 |
  | 马卡龙 (macaron) | 明亮活泼的糖果色 |
- **自定义背景**：任意本地图片，可调 **模糊 / 变暗 / 饱和度 / 填充方式**；也可以选动态极光渐变或纯色。
- **强调色**：10 组预设主色 + 自定义次色，界面圆角、密度（紧凑/标准/宽松）均可调。
- 无边框自绘窗口、界面缩放、悬浮「音频浮动板块」。

### 🎵 曲库与格式
- 递归扫描任意文件夹，**支持 MP3 / OGG / M4A / FLAC / WAV / AAC / OPUS**（同时兼容 `.oga .m4b .mp4 .weba .webm .aiff .wma`）。
- **自动读取标签**（标题/歌手/专辑/流派/年份/音轨号）、**内嵌封面**、同目录 `cover.jpg` 兜底、比特率 / 采样率 / 声道 / 无损标识。
- 没有标签的「裸文件」会按文件名推断，约定为 **「歌名 - 歌手」**（例如 `Refrain - 阿南亮子.mp3` → 歌名 `Refrain`，歌手 `阿南亮子`）；文件名中没有 ` - ` 时整个文件名当作歌名。
- 扫描结果与元数据 **缓存**，二次扫描秒开；解析规则升级时会自动丢弃旧缓存并重建一次曲库。
- 拖拽文件或文件夹到窗口即可导入。
- **流畅拖拽排序**（FLIP 动画），自定义顺序会被记住；也可按标题/歌手/专辑/时长/我的累计听歌时长/播放次数等排序。
- 列表视图 / 网格卡片视图；搜索支持标题、歌手、专辑、格式、文件名。
- 收藏、最近播放、多个播放列表（新建 / 重命名 / 导出 JSON / 导入）。

### ▶️ 播放
- **切歌过渡效果（可切换、可调时长）**：
  - `直接切换` — 无过渡
  - `淡出淡入` — 先渐弱再渐强（带短暂间隙）
  - `交叉淡化` — 两首歌平滑重叠
  - `缓慢融合` — 长交叉淡化，适合慢歌
  - `快速闪接` — DJ 式快速压低再拉起
  - `无缝衔接` — 零间隙，适合连续专辑（会预加载下一首）
- 播放模式：**顺序播放 / 列表循环 / 单曲循环 / 随机播放**（播放栏一键循环切换）。
- **变速不变调**（0.5×–3.0×，Chromium 时间伸缩）与 **独立变调**（−12 ~ +12 半音，自研 AudioWorklet 双抽头颗粒变调器）——两者互相独立，也可以关闭「变速不变调」得到磁带式变速变调效果。
- **10 段参数均衡器**（31Hz–16kHz，±12dB）+ 前置放大，15 组内置预设（流行/摇滚/古典/爵士/人声/低音增强/重低音/高音增强/电子/民谣/夜晚/电影/V型/播客/默认）与自定义预设保存。
- **音效插件系统**（详见下文），可叠加串联。
- 音量 / 静音 / 记忆播放位置 / 自动播放下一首 / 系统媒体键（Windows SMTC，音量弹窗显示曲目并可控制）。

### 🎤 歌词（中文 + 英文）
- 支持 **LRC** 格式，自动识别 **UTF-8 / UTF-16 / GBK / GB18030 / Big5** 编码（中文歌词不会乱码）。
- 查找顺序：同名 `.lrc` → 同目录 `歌词/ lyrics/ lrc/` 子目录 → 父目录 → 曲库根目录歌词夹 → 应用歌词缓存目录 → **音频内嵌歌词**（ID3 USLT / Vorbis LYRICS）；还会按「歌名 / 歌手+歌名」模糊匹配。
- **中英双语**：同一时间戳的一中一英两行会自动合并为「主行 + 翻译行」；也可一键关闭翻译显示。
- 中文字体与英文字体 **分别设置**，按行内容自动切换字体。
- 卡拉OK 染色、滚动居中、点击歌词行跳转播放位置。
- 可 **导入 .lrc 文件**、**内置编辑器** 编辑歌词并保存到歌词库。

### 🖥️ 桌面歌词浮层（独立窗口）
- 无边框、透明、可拖动、可缩放、始终置顶、可 **锁定（鼠标穿透）**。
- **颜色**：常规色 / 当前行色 / 已播过色。
- **字体**：字号、行间距、字重、中文字体、英文字体、对齐方式。
- **阴影**：开关 / 颜色 / 模糊 / X 偏移 / Y 偏移。
- **描边**：开关 / 颜色 / 宽度（任何壁纸上都清晰）。
- 不透明度、显示翻译、显示下一句、卡拉OK 染色、进度条。
- **位置**：任意拖动、一键重置、多显示器指定。
- **很方便**：鼠标悬停即出快捷工具条（上一首 / 播放 / 下一首 / 🎨外观 / 锁定 / 置顶 / 关闭）；在歌词上 **右键即可打开外观快捷面板**（滑块实时预览）；完整设置也在主界面「设置 → 桌面歌词」。

### ⌨️ 自定义快捷键
- 所有操作均可 **自己按键录制**：播放/暂停、上一首/下一首、音量±、静音、快进/后退、收藏、搜索、切主题、均衡器、统计、桌面歌词、迷你播放器、显示主窗口……
- **全局快捷键**（窗口不在前台也生效）+ **媒体键**（播放/暂停/上一首/下一首/停止），可单独开关，并提供「占用检查」。

### 📊 听歌时长统计（核心需求）
- **每日 / 每月 / 每年累计听歌时长**，以及 **日均、有效听歌天数、自然日均**。
- **每首歌的累计听歌时长**：曲库列表直接有一列「累计听歌」，可排序；「正在播放」页也显示当前歌曲累计；统计页有完整的 **每首歌时长排行榜**（含播放次数、上次播放时间）。
- 今日目标进度条、最近 30 天柱状图、最近 12 个月柱状图、按年统计图。
- 单曲最短计入时长可调（默认 5 秒，避免快速切歌刷数据）；可 **导出 JSON / CSV** 与一键重置。

### 🔌 音效插件（类似 QQ 音乐的音效）
内置 **16 个音效插件**：3D 环绕声、大厅混响、房间混响、超重低音、清澈人声、人声消除（卡拉OK）、8D 环绕、夜晚柔和、温暖胆机、摇滚现场、车载音响、录音棚监听、Lo-Fi 磁带、电子舞曲、合唱空间、电话音效、梦幻空间。

- 每个插件有 **可调参数滑块**，可任意组合叠加，实时生效。
- **可导入自定义插件**：
  - `.auroraplugin` / `.json` 描述文件（声明式效果图 + 参数面板，见下文格式）；
  - 直接导入 `wav/ogg/mp3/flac/m4a` **脉冲响应文件**，自动生成卷积混响插件。
- 支持的效果节点：`gain` `biquad`(均衡/滤波) `convolver`(卷积混响) `delay` `chorus` `autoPan` `compressor` `waveshaper`(胆味失真) `vocalsRemover`(声道相减消人声) `stereo`。

### 🔊 音频浮动板块
- 可拖动、可缩放的悬浮面板，实时频谱：**频谱柱 / 镜像柱 / 波形 / 环形 / 粒子** 五种可视化。
- 迷你播放器窗口（独立置顶浮窗）：封面、标题、进度、播放控制、模式、桌面歌词开关、迷你频谱与当前歌词行。

## 📦 安装与运行

### 方式一：安装包（推荐）
运行 `AuroraPlayer-Setup-1.0.0.exe`，安装程序会自动创建 **桌面快捷方式** 和开始菜单项。

### 方式二：免安装绿色版
直接运行 `AuroraPlayer-Portable-1.0.0.exe`，或在应用内「设置 → 数据与关于 → 创建桌面快捷方式」生成桌面图标。

### 方式三：源码运行
```bash
npm install
npm start
```

### 打包（Windows）
```bash
# 方式 A：直接组装免安装绿色版（无需 electron-builder 的二进制组件，最可靠）
node tools/package-portable.js                 # 输出到 %USERPROFILE%\AuroraPlayer
node tools/package-portable.js D:\MyBuild      # 也可指定输出目录

# 方式 B：electron-builder 生成 NSIS 安装包 + 便携版
npm run dist     # 输出到 dist/
npm run pack     # 只生成免安装目录 dist/win-unpacked
```

### 其他命令
```bash
node tools/gen-icon.js                   # 重新生成 assets/icon.ico 与 icon.png
AuroraPlayer.exe --create-shortcut       # 在桌面创建/更新快捷方式
AuroraPlayer.exe --smoke                 # 端到端自检，结果写入 smoke-report.json
AuroraPlayer.exe --verbose               # 输出渲染进程控制台日志
```

> 国内网络若无法直连 GitHub Releases 下载 Electron 二进制，可先设置镜像：
> ```powershell
> $env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"
> $env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"
> npm install
> # 若 npm 因 allowScripts 策略跳过了 electron 的 postinstall，可手动补装运行时：
> node node_modules/electron/install.js
> ```

## ✅ 自检（--smoke）

`AuroraPlayer.exe --smoke` 会启动一次完整的端到端自检，约 40 秒后写出 `smoke-report.json`，包含：

- 界面是否完成启动、各视图能否渲染
- 曲库扫描结果（数量 / 时长 / 标签 / 格式分布）
- 歌词查找与解析行数
- **实际播放验证**：播放 5 秒后检查 `currentTime` 是否推进、Web Audio 分析器是否有信号（证明解码与音频图可用）
- 6 套主题、6 种切歌过渡、4 种播放模式、均衡器、变速变调、音效插件开关
- 听歌时长统计是否写入
- 桌面歌词窗口与迷你播放器窗口能否创建与渲染

## 🧩 自定义音效插件格式

把下面的 JSON 保存为 `我的音效.auroraplugin`（或 `.json`），在「音效插件 → 导入插件」中选择即可：

```json
{
  "name": "我的低音炮",
  "author": "你的名字",
  "version": "1.0.0",
  "desc": "加强 60Hz 与 120Hz 的低频冲击",
  "category": "动态",
  "params": [
    { "key": "gain", "label": "强度", "min": 0, "max": 12, "default": 6, "unit": "dB" }
  ],
  "graph": [
    { "type": "biquad", "params": { "type": "lowshelf", "freq": 90, "gain": "{gain}", "q": 0.7 } },
    { "type": "biquad", "params": { "type": "peaking", "freq": 60, "gain": "{gain}", "q": 0.9 } },
    { "type": "compressor", "params": { "threshold": -20, "knee": 14, "ratio": 5, "attack": 0.004, "release": 0.2 } }
  ]
}
```

- `params` 里的 `key` 可以用 `"{key}"` 或 `"-{key}"` 的形式在 `graph` 中引用，界面会自动生成滑块。
- `graph` 中每个节点串联连接，`type` 支持：`gain` `biquad` `convolver` `delay` `chorus` `autoPan` `compressor` `waveshaper` `vocalsRemover` `stereo`。

## 🛠 技术要点

- **Electron** 无边框多窗口：主窗口 + 桌面歌词浮层 + 迷你播放器。
- **自定义 `aurora://` 协议** 统一同源地提供页面与本地音频（支持 HTTP Range 分段流式读取，保证拖动进度条即时响应），并让 `<audio>` → Web Audio 的分析器不被跨域污染。
- **双解码器 (dual deck) + Web Audio 图**：
  `deckA/deckB → 输入 → 10×BiquadFilter → 前置放大 → 插件链 → 变调 Worklet → Analyser → 主音量 → 输出`
  双解码器让交叉淡化/闪接等过渡效果可以真正重叠播放。
- **自研变调 AudioWorklet**：双抽头颗粒重叠相加 + 正弦窗归一化，与变速完全解耦。
- 元数据由 `music-metadata` 解析（打包时通过 `asarUnpack` 解包为真实文件以便 ESM 动态导入）；封面用 Electron `nativeImage` 缩放后缓存为 JPEG。
- 渲染层零框架、纯原生 JS/CSS，启动快、体积小。
